# Assignment #3 — Media Queries + Bootstrap

Copy of the Spider-Man fan site for Assignment #3 only (as allowed in the PDF).
The root folder keeps the custom CSS site from Assignments #1–#2.

## Open locally
Open `assignment3/index.html` in a browser, or from the project root:

```bash
python -m http.server 5173
```

Then visit: http://127.0.0.1:5173/assignment3/

## What was implemented

| Task | Where |
|------|--------|
| 1 Responsive typography (MQ) | `css/media-queries.css` + Home / Movies / About |
| 2 Card group MQ (3 / 2 / 1) | Home + About (`.mq-card-row`) — no Bootstrap for layout |
| 3 Bootstrap grid `col-lg-6` & `col-lg-4` | Home, Movies, About, Contact |
| 4 Spacing utilities `m-` `p-` `mt-lg-*` `px-sm-*` | All pages |
| 5 Bootstrap navbar + hamburger | All pages |
| 6 Bootstrap buttons + `btn-group` | All pages |
| 7 Carousel (9 images) | Home |
| 8 Bootstrap cards / card-group | Home, Movies, About, Contact |
| 9 Bootstrap form | Contact |
| 10 Accessibility | `<nav>`, `<button>`, labels, contrast theme |
